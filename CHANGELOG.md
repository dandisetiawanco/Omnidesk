# Changelog

All notable changes to OmniDesk are documented here.

## [0.1.0] - 2026-11-24

### Added

- Independent cross-platform monorepo built with Tauri 2 (Rust), React 19 + TypeScript + Vite, and Python 3.12 + FastAPI + SQLite.
- Omni Glass adaptive design system with WCAG AA verified Light and Dark themes, platform vibrancy hooks, reduced-motion support, and Performance Mode.
- Hardware, display, OS permission, and runtime capability detection across macOS, Windows, and Linux (separating Wayland and X11).
- Deny-by-default permission engine with 6 risk tiers, scoped directory validation, prompt-injection isolation, secret redaction, OS keyring vault, authenticated loopback IPC, and Emergency Stop.
- Flagship Downloads Organization & Excel (`.xlsx`) Report pipeline with SHA-256 duplicate verification, dry-run approval previews, zero deletions, and SHA-256-verified Undo rollback.
- Real Playwright Chromium browser navigation, DOM extraction, and safe form preparation.
- Visual Workflow Studio with pan, zoom, minimap, keyboard/pointer positioning, undo/redo, bounded loops, and versioned JSON export.
- Flagship Teach Mode explicit demonstration recorder with automatic password/secret redaction, variable extraction, and reusable workflow synthesis.
- Unified AI model provider manager (Ollama, OpenAI, Google Gemini, Anthropic Claude, OpenAI-compatible) and MCP JSON-RPC interoperability endpoint.
- Cross-platform GitHub Actions validation workflow and release signing documentation.
