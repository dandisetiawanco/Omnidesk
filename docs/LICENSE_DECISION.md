# License Decision: Apache License 2.0

OmniDesk is released under the **Apache License 2.0**.

## Rationale

1. **Open-source adoption and commercial viability**: Apache-2.0 allows individuals, startups, and enterprise teams to adopt, inspect, extend, and deploy OmniDesk freely without copyleft friction while preserving copyright and attribution notices.
2. **Explicit patent grant**: Unlike MIT or BSD licenses, Apache-2.0 includes an express patent license and defensive retaliation clause, which is important for enterprise automation and security review boards.
3. **Ecosystem compatibility**: Apache-2.0 aligns cleanly with Tauri 2 (MIT/Apache-2.0 dual-licensed), Rust ecosystem crates, React (MIT), FastAPI (MIT), and Playwright (Apache-2.0).
4. **Commercial extensibility**: Future commercial modules (such as managed enterprise policy servers, team collaboration sync, or curated workflow marketplaces) can build cleanly on top of the open-source local core.
